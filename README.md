# Marble Physics Game

Play the current browser prototype by opening [Ocean_Photo_Bubble_Shooter.html](Ocean_Photo_Bubble_Shooter.html) on a phone or desktop. The game is self-contained and works without a server or internet connection.

Aim by dragging on the playfield and release to fire. Match three or more marbles. The bottom buttons swap the next color, trigger a blast, and toggle sound. The MAP button currently shows instructions; it does not open a level map.

[reference/1177.jpg](reference/1177.jpg) is the visual target. The browser prototype now fills the playfield with the photo and begins with about 776 marbles. Cleared marbles reveal matching parts of the photo. Its ocean scene, cannon, and buttons still use simpler drawn artwork. It is not a Unity project or a faithful reproduction of the reference yet.
