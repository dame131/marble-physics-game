# URP Marble Materials

Create materials with **Universal Render Pipeline/Lit** and keep Specular Highlights enabled.

| Match ID | Name | Base Color | Metallic | Smoothness |
|---:|---|---|---:|---:|
| 0 | Crimson | `#D60A00` | 0.10 | 0.95 |
| 1 | Gold | `#E8A200` | 0.85 | 0.92 |
| 2 | Amber | `#FF6600` | 0.30 | 0.90 |
| 3 | Emerald | `#00A300` | 0.10 | 0.95 |
| 4 | White Pearl | `#FFF0D0` | 0.05 | 0.98 |
| 5 | Royal Purple | `#6A0DAD` | 0.35 | 0.92 |
| 6 | Royal Blue | `#002366` | 0.40 | 0.95 |
| 7 | Electric Blue | `#00E5FF` | 0.20 | 0.98 |
| 8 | Ice Blue | `#A5F2F3` | 0.15 | 0.96 |

Use an HDR environment/skybox and Reflection Probe to get the glossy glass/stone look.

For the initial playable test, use these same Match IDs in both `MarbleShooter` and `MarbleLevelBuilder`.
